# 数算 · 个人数学计算能力训练平台

一个面向成年人、用于提升口算 / 心算速度与数字敏感度的训练网站。它不是计算器，而是具备
**训练、测试、统计、分析与成长记录**的完整平台。第一阶段纯前端（无后端、无登录），数据全部保存在浏览器本地。

技术栈：**Vue 3 + TypeScript + Vite + Element Plus + ECharts**，模块化分层，方便后续扩展后端与云端同步。

---

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务 → http://127.0.0.1:5174
```

生产构建 / 预览：

```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览构建产物
```

出题引擎自检（强烈推荐改完题目后跑一次）：

```bash
npm run verify
```

它会用一个**独立实现的表达式解析器**交叉验证全部 22 个题型 × 4 个随机种子 × 250 题，
以及 5 个难度等级各 1000 题，断言「题面与答案自洽」，重点覆盖整除、带余数、小数精度、
混合运算优先级与括号 —— 防止「答案自己都判不对」。

## 功能总览

| 页面 | 路径 | 说明 |
|---|---|---|
| 仪表盘 | `/` | 今日训练次数 / 答题数 / 正确率 / 平均用时 / 连续天数 / 累计题数 + 近 7 天趋势 + 智能建议 |
| 基础训练 | `/train` | 22 个题型（加减乘除 + 混合运算），或按 L1~L5 难度，10/20/30/50 题 |
| 限时挑战 | `/timed` | 30 秒 / 1 分钟 / 3 分钟 / 5 分钟 / 自定义，倒计时 + 每题计时 + 自动下一题 |
| 错题本 | `/mistakes` | 自动记录错题、展示正确答案与解析步骤、专项重练、标记掌握 |
| 成绩统计 | `/stats` | 每日 / 每周 / 每月图表、题型正确率、模式分布、逐次训练记录表 |
| 智能训练 | `/smart` | 根据近 20 题正确率自动升降难度，锁定薄弱题型生成专项练习 |

### 交互细节

- 键盘直接输入答案，**Enter 提交**，自动聚焦输入框
- 答对绿色反馈；答错红色反馈并展示正确答案 + 计算步骤
- 支持「自动进入下一题」（可在设置里关闭），全程无刷新
- 训练中显示进度条 / 倒计时，支持**暂停 / 继续 / 提前结束**
- 结束后展示成绩报告（正确率、平均/最快用时、错题回顾）

## 出题正确性设计（关键）

- **整除**：先随机出「除数 × 商」，反推被除数，保证 `a % b === 0`。
- **带余数**：先出「除数 × 商 + 余数」，约束 `0 < 余数 < 除数`，答案判「商 + 余数」双字段。
- **小数精度**：小数统一用「整数 + 缩放位」表示（`值 = int / 10^scale`），全程整数运算，规避 `0.1 + 0.2` 的浮点误差。
- **混合运算优先级与括号**：用表达式树生成并求值，序列化时按优先级自动补括号；判分用容差 1e-6。
- **判分**：整数精确相等；小数数值容差比较；商余数支持 `7余5` / `7 余 5` / `7,5` / `7r5` 等输入。

## 目录结构

```
src/
├─ core/               # 纯函数核心（可单测，无 UI 依赖）
│  ├─ rng.ts           # mulberry32 可复现随机数
│  ├─ decimal.ts       # 小数整数化表示
│  ├─ expression.ts    # 混合运算表达式树 + 求值 + 序列化 + 步骤
│  ├─ generator.ts     # 22 个题型出题器 + 难度映射
│  ├─ evaluate.ts      # 判分
│  └─ adaptive.ts      # 智能训练自适应算法
├─ stores/             # 响应式状态
│  ├─ persistence.ts   # 存储接口（localStorage 实现，可换后端）
│  ├─ settings.ts      # 主题 / 自动下一题 / 难度等
│  └─ history.ts       # 训练记录 + 错题本 + 统计聚合
├─ composables/
│  └─ useTraining.ts   # 训练流程编排（出题/计时/判分/暂停/成绩）
├─ components/         # 头部、统计卡、图表封装、训练面板
├─ views/              # 6 个页面
└─ utils.ts
scripts/
├─ verify-entry.ts     # 出题引擎自检逻辑
└─ verify-generator.mjs # esbuild 打包后运行自检
```

### 分层与扩展

- **核心层**（core）不依赖任何 UI / 存储，纯函数，未来可直接复用并单测。
- **持久层**（persistence）抽象出 `StorageAdapter` 接口，第一阶段用 localStorage，接入后端时只需新增一个 `ApiAdapter` 实现即可，上层零改动。
- **编排层**（useTraining）把「出题 → 计时 → 判分 → 记录」串成一条流程，各页面共用。

## 功能测试清单

1. **基础训练**：选择「乘法口诀」→ 开始 → 输入答案回车，验证绿色/红色反馈、自动进入下一题、进度条递增；选「难度 L5」验证出题为多位数/混合/括号。
2. **带余数除法**：题型选「带余数除法」，按提示输入 `商余余数`（如 `7余5`），验证判分。
3. **限时挑战**：选「30 秒」→ 开始，验证倒计时、暂停/继续、到时自动结束并出报告。
4. **错题本**：故意答错几题 → 结束 → 进「错题本」，验证错题已记录、含解析步骤、可专项重练、可标记掌握。
5. **统计**：完成几组训练 → 进「成绩统计」，切换每日/每周/每月，验证图表与记录表数据一致。
6. **智能训练**：多次答题后进入，验证推荐难度与薄弱题型提示随正确率变化。
7. **主题 / 响应式**：右上角切换浅色/深色/跟随系统；缩小窗口验证移动端布局。
8. **数据持久化**：刷新页面，历史记录、错题本、设置均保留。

## 已知边界

- 数据仅存本机浏览器（localStorage），换浏览器 / 清除站点数据后不保留（纯前端版本的取舍）。
- 生产构建产物 `dist/` 直接部署到任意静态服务器即可；路由用 hash 模式，无需服务端重写。
- ECharts + Element Plus 体积较大，构建已按库拆分为独立 chunk，首次加载会稍慢，后续有缓存。
